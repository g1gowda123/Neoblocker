## 2025-06-21 - Offload Iterative DOM Node Filtering to Native C++ Engine
**Learning:** In high-frequency MutationObserver callbacks parsing large DOM trees (like YouTube), retrieving all elements matching a base selector via JavaScript `document.querySelectorAll()` and subsequently filtering them iteratively via JavaScript property comparisons (e.g., `if (el.dataset.blocked) return;`) incurs significant overhead.
**Action:** Append the exclusion criteria directly to the CSS selector string using pseudo-classes like `:not([data-blocked="true"])`. This offloads the filtering to the browser's highly optimized native C++ engine, sharply reducing the number of nodes returned to the JavaScript execution environment.
