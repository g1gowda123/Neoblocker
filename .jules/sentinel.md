## YYYY-MM-DD - SSRF Protection via DNS Rebinding Risk
**Vulnerability:** SSRF mitigation that resolves host to IP and replaces it in the URL (DNS pinning for SSRF protection) breaks SNI and HTTP Host headers, preventing crawling of sites behind CDNs or virtual hosts.
**Learning:** Rewriting URLs with resolved IPs breaks HTTPS and multi-tenant hosting. The crawler must retain the original URL, and SSRF must be handled by validating the IP without rewriting, or configuring the HTTP client/crawler to reject private IPs internally.
**Prevention:** Validate IPs strictly using `ipaddress` but pass the original unmodified URL to the crawler, accepting that DNS rebinding is a TOCTOU risk that must be handled deeper in the network stack or by configuring the HTTP client explicitly, rather than rewriting the URL.
