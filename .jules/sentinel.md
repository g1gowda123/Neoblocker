## 2024-06-23 - [Fix SSRF in crawler URL processing]
**Vulnerability:** The FastAPI endpoint `/verify` accepts a `source_url` which is fetched using `AsyncWebCrawler` with zero URL scheme or target IP validation, enabling Server-Side Request Forgery (SSRF) and Local File Inclusion (LFI).
**Learning:** External libraries and crawler utilities do not inherently protect against internal network sweeping or reading local file systems. Furthermore, using synchronous DNS resolution `socket.gethostbyname()` to validate URLs within an `async def` endpoint blocks the entire `asyncio` event loop, opening up the system to DoS attacks.
**Prevention:** Always validate schemes (e.g. `http`/`https`) and parse destination IPs to ensure they are public/external before dispatching a crawler. Always utilize asynchronous DNS resolution `asyncio.get_running_loop().getaddrinfo()` for network I/O in async applications to prevent blocking the event loop.
